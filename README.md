#AI-Powered Criminal Network Analysis System

## Project Overview
This project analyzes connections between persons and related entities using graph analysis techniques.

The system represents relationships between persons, phone numbers, vehicles, locations, organizations, and financial transactions.

## Objectives
- Identify connections between persons.
- Analyze relationships using graph analysis.
- Visualize network connections.
- Display network information through a dashboard.
- Explore relationships between different entities.

## Technologies Used
- Python
- Pandas
- NetworkX
- Neo4j
- Streamlit
- Matplotlib
- Scikit-learn

## Project Structure
- data/ - Contains sample CSV datasets.
- src/ - Contains Python source code.
- dashboard/ - Contains the Streamlit dashboard.
- README.md - Project documentation.
